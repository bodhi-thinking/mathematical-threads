# Mathematical Threads

**Story → Playground → 10 Puzzles → Next Story**

The initial repository contains dummy content only. Series 1 content will be added after the local/GitHub/Vercel shell is confirmed.

## Local

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## GitHub

```bash
git init
git add .
git commit -m "Initial Mathematical Threads course shell"
git branch -M main
git remote add origin <YOUR_GITHUB_REPOSITORY_URL>
git push -u origin main
```

## Vercel

Import the GitHub repository into Vercel. It should detect Next.js automatically. No environment variables are required for this initial version.
